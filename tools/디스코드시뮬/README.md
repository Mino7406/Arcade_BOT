# 🎮 디스코드 시뮬레이터

실제 봇 코드(`index.js` 와 `handlers/`·`commands/`·`forms/`)를 **고치지 않고 그대로** 가짜 디스코드 위에서 돌려,
브라우저에서 디스코드처럼 눌러 보며 "무엇을 누르면 어떤 메시지가 뜨는지"를 확인하는 개발 도구입니다.
(`tests/카드화면.js` 는 화면 모양만 보여 주지만, 이 도구는 버튼·선택 메뉴·입력창·채팅이 **진짜로 동작**합니다.)

## 실행

```powershell
npm run 시뮬                             # = node tools/디스코드시뮬/실행.js → http://localhost:5173
node tools/디스코드시뮬/실행.js 8080     # 포트 바꾸기
```

- 봇 코드를 임시 폴더에 복사해서 돌리므로 **진짜 `DB/` 는 건드리지 않습니다.** 끄면(Ctrl+C) 임시 폴더도 지워집니다.
- 디스코드 토큰·네트워크가 필요 없습니다(패치노트 감시·퀴즈/레이드 자동 출현은 꺼 둠).

## 고친 것 바로 확인하기

- **`화면.html`**: 서버와 분리된 한 파일이라 고치고 **저장만 하면 열려 있는 브라우저가 자동 새로고침**됩니다(서버가 원본 파일을 직접 읽음).
- **파일 열기(더블클릭)**: `화면.html` 을 탐색기에서 바로 열어도 실행 중인 서버(`localhost:5173`)에 붙습니다.
  다른 포트면 `화면.html?server=http://localhost:8080`. 서버가 꺼져 있으면 위에 안내 띠가 뜨고 자동 재연결합니다.
- **봇 코드(index.js·handlers/·commands/·forms/·config.js·assets/)**: **저장하면 자동으로** 새로 복사해 재시작합니다(환경 설정은 유지, 메시지·진행 중인 게임은 초기화). 커밋·푸시 전의 작업 폴더를 그대로 쓰니 고친 직후 바로 확인할 수 있습니다.
  자동이 싫으면 `--수동` 으로 켜고 왼쪽 아래 **🔄 봇 코드 다시 불러오기** 버튼을 쓰세요.
- **다른 컴퓨터(집 등)**: 이 폴더를 가져온 뒤(`git pull`) `npm run 시뮬` 한 줄이면 같은 방식으로 돕니다.

## 화면 구성

| 위치 | 내용 |
|---|---|
| 왼쪽 | 채널 목록(config.js 의 실제 채널 ID), 내 DM, **지금 조작하는 사람** 고르기 |
| 가운데 | 메시지(컴포넌트 v2·임베드·이미지·나만 보이는 메시지) + 입력창 (`/` 로 슬래시 명령어, 그냥 치면 채팅) |
| 오른쪽 ⚙️ 환경 설정 | 아래 "환경 설정" 참고 |
| 오른쪽 🧪 동작 기록 | 누를 때마다 봇이 한 일을 순서대로(reply / update / showModal / editReply / followUp …) |

## 동작 확인 방식

- **버튼 · 선택 메뉴 · 입력창(모달) · 슬래시 명령어 · 채팅**을 실제 `interactionCreate` / `messageCreate` 핸들러로 보냅니다.
  채널 제한, 권한 확인, 오류 시 "처리 중 오류" 안내까지 index.js 그대로입니다.
- 나만 보이는(🔒) 메시지는 그 사람으로 볼 때만 보입니다 → 사람을 바꿔 가며 확인하세요.
- 링크 버튼은 새 탭으로 열립니다.
- 입력창은 디스코드처럼 필수 칸·최소/최대 글자 수를 검사한 뒤 제출됩니다.

### 자동으로 잡아 주는 문제 (동작 기록에 노랑/빨강으로 표시)

- 아무 응답도 안 함 → 디스코드에선 "상호작용 실패"
- 응답이 3초 초과 → "Unknown interaction"
- 이미 응답한 상호작용에 또 `reply`/`update` (InteractionAlreadyReplied), 응답 전 `editReply`
- 컴포넌트 v2 규칙 위반(content/embeds 섞기, 컴포넌트 40개·글자 4000자 초과, 평문으로 되돌리기 …)
- `custom_id` 100자 초과·중복, 버튼 글자 80자 초과, 한 줄 버튼 5개 초과 등
- 핸들러에서 난 예외와 스택
- 시뮬레이터가 아직 흉내 내지 못하는 디스코드 API 호출 (🧩 표시 — 추가가 필요하다는 신호)

## 환경 설정 (상황별 확인)

오른쪽 ⚙️ 탭에서 바꾸면 바로 적용됩니다.

- **서버**: 테스트 서버 / 본서버 — 채널 제한 규칙이 서버마다 다르게 적용됩니다.
- **유저별**: 이름, 관리자(ADMIN_IDS), 소유자(OWNER_IDS), 역할(뉴비부스트·내전 알림·Steam), 음성채널 접속, DM 차단
- **시간**: 가상 시계를 +/- 시간 이동 (모집 시각·알림·일일 한도 등)
- **응답 지연(ms)**: 3500 으로 두면 3초 초과 상황 재현
- **모든 유저 DM 차단**
- **상황 만들기**: 레이드 소환/종료 (레이드 중 놀이터 일시 정지 확인)
- **상황 저장/불러오기**: 현재 설정을 이름 붙여 `tools/디스코드시뮬/상황저장.json` 에 저장 (예: "본서버 · 일반유저 · 레이드 중")

## 한계

- 디스코드 서버가 아니라 흉내이므로, 실제 서버 권한·캐시·레이트리밋은 재현하지 않습니다.
- 롤/발로란트 전적 같은 외부 API 는 키·네트워크가 없으면 실패 안내가 뜹니다(그 자체가 확인 대상).
- 앱 이모지(`rec_…`, 해킹 툴 등)는 서버에 등록된 ID 가 없어 이모지 그림이 비어 보일 수 있습니다.
- 모달의 `awaitModalSubmit`, 스레드, 음성 접속 이벤트 자동 발생 등은 아직 없습니다.

## 파일

| 파일 | 역할 |
|---|---|
| `실행.js` | 임시 폴더에 봇 코드를 복사해 서버를 띄움 |
| `서버.js` | 가짜 Client·메시지 저장소·상호작용 객체 + HTTP/SSE API |
| `화면.html` | 디스코드 모양 화면 + 환경 설정 패널 (한 파일) |
