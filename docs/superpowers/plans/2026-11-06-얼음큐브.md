**Goal:** 세 번째 레이드 몬스터 🧊 얼음 큐브(가칭)를 넣는다 — "방어하면 냉기가 쌓이고 3중첩이면 빙결" 규칙을 가진 몬스터.

**Architecture:** 몬스터 데이터는 `Monster/얼음큐브.json` 하나. 냉기 규칙은 몬스터 파일의 최상위 `chill` 블록이 있을 때만 켜지므로 슬라임·독버섯은 그대로다. 엔진(`레이드전투.js`)에 새 효과 `chill`과 보호막 반격 `chillOnHit`, 화면 글자(`레이드.js`)·그림(`레이드그림.js`)에 냉기 배지·빙결 연출을 더한다.

**Tech Stack:** Node.js, discord.js 14, 자체 PNG 그리기(`레이드그림.js`), 테스트는 `node tests/raid/실행.js`(흐름 테스트) · `node tests/raid/밸런스시뮬.js <id>`(시뮬).

**Spec:** `docs/superpowers/specs/2026-11-06-신몬스터-3종-design.md` 4장(얼음 큐브) · 5장(공통 작업)

## Review Focus

1. **냉기 블록이 없는 몬스터**(슬라임·독버섯): 방어해도 냉기가 생기면 안 된다 → Task 1 테스트 `슬라임은 방어해도 냉기 없음`.
2. **재시작 전 저장된 전투**(`chillStacks` 칸 없음): 0으로 보고 오류 없이 진행 → Task 1 테스트 `냉기 칸 없는 예전 기록은 0`.
3. **쓰러진 사람**: 서리 숨결·방어 규칙으로 냉기가 쌓이지 않고, 쓰러지면 냉기가 0이 된다 → Task 1 테스트 `쓰러진 사람은 냉기 없음`.
4. **같은 턴 필살기 기절 + 빙결**: 행동 불가가 한 번만 걸리고(다음 턴), 냉기는 0으로 → Task 1 테스트 `필살기와 빙결이 겹쳐도 한 턴만`.
5. **빙결된 턴**: 행동을 못 하니 냉기가 녹지도 쌓이지도 않는다 → Task 1 테스트 `빙결 중엔 냉기 그대로`.

## 결정해 둔 규칙 (Task 1이 구현)

몬스터 파일 최상위:
```json
"chill": { "freezeAt": 3, "guardStacks": 1, "melt": 1,
           "status": { "name": "냉기", "emoji": "❄️" },
           "freezeStatus": { "name": "빙결", "emoji": "🧊", "fx": "ice" } }
```
- 파티원 칸 `chillStacks`(없으면 0).
- **행동하는 즉시** 냉기 증감: 방어 `+guardStacks` · 공격·스킬 `-melt`(0 밑으로 안 감) · 보호막(`chillOnHit`) 턴에 몬스터에게 피해를 준 행동은 `-melt` 대신 `+chillOnHit` · 치유사 스킬은 전원 냉기 0 · 회복약은 본인 냉기 0 · 기절/빙결로 못 움직인 턴은 변화 없음.
- **빙결 판정**: 아군 행동이 모두 끝난 뒤(몬스터 행동 전) 한 번, 몬스터 기술로 냉기가 쌓인 뒤 한 번. `chillStacks >= freezeAt`이면 `stunTurn = turn + 1`, `stunStatus = freezeStatus`, `chillStacks = 0`, `last.effects[userId] = 'freeze'`, 로그 `🧊 **이름** 빙결! 다음 턴 행동 불가`. 이미 다음 턴 기절이면 냉기만 0.
- 새 효과 `effect: "chill"`(target single/all): 맞은 사람 냉기 `+stacks`(분노 중이면 `rageStacks ?? stacks`). **방어해도 걸린다.** `last.effects[userId] = 'chill'`.
- 보호막 기술의 `chillOnHit`(1 이상 정수): 보호막 기술을 쓸 때마다 `battle.shieldChill = move.chillOnHit ?? 0`(슬라임 단단해지기는 0). 보호막이 켜진 턴(`isShielded`)에만 쓴다.
- 참고: 갑옷 턴에는 방어(+1)도 때리기(+1)도 냉기가 쌓인다. 녹는 길은 피해 없는 스킬(도발·치유의 빛)과 회복약뿐 — 의도된 압박이지만 너무 아프면 Task 4에서 조정.
- 쓰러지면 냉기 0. 1중첩 이상이면 HP가 가득해도 회복약을 마실 수 있다(독과 같음).

## 얼음 큐브 시작 수치 (`Monster/얼음큐브.json`)

| 키 | name | target | 값 | fx |
|---|---|---|---|---|
| `attack` | 얼음 박치기 | single | damage [8,10] | attack |
| `frost` | 서리 숨결 | all | damage [4,6], effect chill, stacks 1, rageStacks 2 | frost |
| `armor` | 가시 얼음 갑옷 | none | effect shield, effectRate 0.6, chillOnHit 1 | charge |
| `smash` | 필살 빙하 낙하 | all | damage [15,19], effect stun, status = 빙결(🧊, fx ice), readyPose `ready` | icefall |

- `id: "icecube"`, `name: "얼음 큐브"`, `emoji: "🧊"`, `rageName: "폭주한 얼음 큐브"`, `baseHp: 6500`(Task 4에서 조정), `rage: { hpRatio: 0.5, damageRate: 1.5 }`.
- `intentWeights.normal { attack: 4, frost: 3, armor: 2, smash: 1 }`, `rage { attack: 3.5, frost: 3, armor: 2, smash: 1.5 }`.
- 예고 문구: attack "몸을 데굴 굴릴 준비를 한다...", frost "입김이 하얗게 서리기 시작한다...", armor "몸 모서리에 얼음 가시가 돋는다...", smash "💥 필살기를 준비 중입니다! 방어하세요!".
